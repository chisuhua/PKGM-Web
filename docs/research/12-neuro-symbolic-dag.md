## 一、架构全景：四层异质记忆体

| 记忆层级 | 存储范式 | 核心技术组件 | 解决的核心矛盾 |
| :--- | :--- | :--- | :--- |
| **Tier-0 (工作记忆)** | 静态 Prefix Cache | vLLM RadixAttention | 极致低延迟 (<50ms)；承载全局指令与热点摘要 |
| **Tier-0.5 (导航记忆)** | 分层 DAG + 动态 KV | CPU 骨架 + GPU 血肉 + 语义锚点 | 无限渐进加载 vs 注意力稀释；结构化钻取 vs 机械翻页 |
| **Tier-1 (语义记忆)** | 模型权重 (LoRA/FT) | 专用检索模型 + 拒答训练 | 精确事实召回 vs SVD 幻觉；内化即检索；保留显性无知 |
| **Tier-2 (档案记忆)** | 磁盘索引 (Hybrid Search) | LanceDB + BM25 + Rerank | 海量存储成本 vs 按需访问；安全网与溯源兜底 |

### 核心设计哲学

- **Tier-0 是"桌面"**：只放全局指令和当前会话摘要，严格静态，保证基线响应速度。
- **Tier-0.5 是"交互式地图"**：DAG 仅作为导航骨架驻留 CPU/RAM，KV Cache 作为语义血肉按需载入 GPU。通过"语义锚点"实现平滑过渡，通过"智能预取"掩盖 I/O 延迟，在有限显存内实现无限深度的认知钻取。
- **Tier-1 是"内化直觉"**：扁平、高频、精确的知识已炼入权重，无需额外显存，支持高并发。
- **Tier-2 是"外部档案馆"**：仅在前三层置信度不足时触发，确保长尾知识不丢失。

## 二、Tier-0.5 DAG 引擎详细规范

| 维度 | 规范 | 依据与红线 |
| :--- | :--- | :--- |
| **适用边界** | 仅用于查询深度 >3 层、分支复杂度 >5 的知识域 | 扁平知识禁止 DAG 化 |
| **双层分离** | 骨架层(CPU/RAM) ≤5GB；血肉层(GPU/HBM) 单节点 ≤4K tokens | 防止元数据挤占推理显存 |
| **语义锚点** | 每条 DAG 边必须携带过渡提示词，作为子节点 KV 加载时的 Prefix | 消除"机械翻页感"，保证 Softmax 注意力连续 |
| **预算控制** | 活跃 KV 块总数 ≤8；超出时按 LRU+注意力分数混合淘汰 | 防止显存碎片化与状态污染 |
| **智能预取** | 基于当前节点+用户意图，异步预取 Top-3 候选子节点 KV | 将串行加载延迟从 150ms 降至 <30ms |
| **回退机制** | DAG 导航连续 2 次置信度 <τ 时，自动降级至 Tier-1/Tier-2 | 防止陷入错误路径死循环 |

## 三、数据治理管线：从 Raw 到 DAG

1. **RIA 强制编译**：所有进入 Tier-1 的数据必须经过 Reading-Interpretation-Appropriation 三段式处理。
2. **DAG 领域识别**：仅当某知识域满足"深度>3 层 & 分支>5"时，才启动 DAG 编译流程。
3. **语义锚点编写**：DAG 每条边必须生成过渡提示词并经语义连贯性校验。无锚点的边 = 无效边。
4. **红链负样本化**：将知识库中的红链显式标注为 `<Query, "当前知识库无可靠答案", Related_Clues>`，作为 Tier-1 拒答训练集 + DAG 导航终止信号。
5. **合成数据增强**：LLM 生成 5-10x 变体问答对，人工审核错误率 <5% 方可用于 Tier-1 微调。

## 四、查询推理流程：四阶段自适应路由

```
Query
  ↓
├─ Tier-0 静态命中? → 直接生成 + 引用 (TTFT <50ms)
├─ Tier-0.5 DAG 导航? → 渐进加载 KV + 语义锚点注入 → 置信度达标? → 生成 + DAG 路径溯源
├─ Tier-1 专用模型召回 → 高置信度? → 生成 + LoRA 权重溯源
├─ Tier-2 混合检索 + Rerank → 生成 + 原始片段引用
└─ 查询日志记录 → 反馈至数据治理管线
```

## 五、进化闭环

| 信号源 | 触发动作 | 目标层级 |
| :--- | :--- | :--- |
| Tier-1 频繁拒答 | 自动生成"知识缺口报告"，推送至人工编译队列 | Tier-1 ← Human |
| Tier-2 高频被访问 | 相关条目自动晋升为 Tier-1 微调候选 | Tier-2 → Tier-1 |
| DAG 路径频繁中断 | 标记该子图为"结构缺陷"，优先重编译 | Tier-0.5 ← Human |
| Tier-0.5 预取命中率 <30% | 调整预取策略或简化 DAG 粒度 | Tier-0.5 Auto |
| 用户修正/点赞 | 作为 RLHF 信号更新 Tier-1 模型 + DAG 锚点 | All |
