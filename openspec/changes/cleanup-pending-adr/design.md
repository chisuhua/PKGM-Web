# 设计

## 方案选择

推荐方案：**废弃 PENDING_ADR_TOPICS.md，内容转移到 `docs/README.md` 附录**

理由：
1. 消除编号冲突的唯一干净方式：删除旧编号，议题按新编号体系纳入 `docs/README.md`
2. 这些议题（知识老化、多模型协作、查询语言、跨项目绑定）与当前 Phase 0 全栈架构讨论正交，保持 `docs/README.md` 作为唯一议题入口
3. 议题详情不重要到需要独立文件——每个议题只有几行说明，附录足够承载

## 具体操作

### 1. 修改 `PKGM-Wiki/docs/PENDING_ADR_TOPICS.md`

在文件顶部添加 Deprecated 标记：

```markdown
> **⚠️ 已废弃（2026-07-18）**：本文件内容已迁移至 `docs/README.md` §附录。
> 编号冲突（ADR-018~021 与新架构跨项目 ADR 编号重叠）已通过迁移解决。
> 请注意：本文件中的 ADR-018（知识老化与更新）已作为 `adr-018-knowledge-aging.md` 创建，本文件状态标记未及时更新。
> 请勿再引用本文件。
```

并在文件末尾保持历史记录以备追溯。

### 2. 在 `docs/README.md` 末尾新增附录

标题：`## 附录：历史待定议题（迁移自 PKGM-Wiki PENDING_ADR_TOPICS.md）`

表格：

| 原编号 | 新编号 | 标题 | 说明 | 优先级 |
|--------|--------|------|------|--------|
| ADR-018 | adr-031 | 知识老化与更新 | Wiki 页面过时标记、定期审查、自动归档 | 🟢 P2 |
| ADR-019 | adr-032 | 多模型协作策略 | LLM 模型分工、降级策略、成本控制 | 🟡 P1 |
| ADR-020 | adr-033 | 知识图谱查询语言 | 图谱查询方式（CLI/API/NLQ） | 🟢 P2 |
| ADR-021 | adr-034 | 跨项目知识绑定 | 项目与知识图谱的绑定方式 | 🟢 P2 |

使用 adr-031~034 编号，明确这些是"Phase 0 范围外的未来议题"。
